# Security Policy

This policy applies to DeployDesk, known in Chinese as 发布舱.

## Supported Versions

Security fixes target the latest version on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities that expose credentials,
remote command execution risks, unsafe file deletion, path traversal, or SSH
authentication problems.

Report privately to the project maintainers through a private GitHub security
advisory or another private channel configured by the repository owner.

## Sensitive Data

Do not publish real deployment configurations, passwords, private keys, server
addresses, usernames, release notes containing customer data, or screenshots that
show sensitive infrastructure details.
