# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project uses semantic version
numbers where practical.

## [0.6.0] - 2026-06-14

### Changed

- Rebuilt the app as a pure Rust `eframe/egui` desktop application.
- Moved Cargo metadata to the repository root.
- Removed the historical Vue, Vite, Node, and Tauri project files.
- Updated repository docs and maintenance templates for the Rust-only codebase.

## [0.5.0] - 2026-03-10

### Added

- DeployDesk Tauri desktop application shell.
- Project configuration management.
- SSH/SFTP deployment workflow.
- Release history and rollback support.
- Local operation log page.
